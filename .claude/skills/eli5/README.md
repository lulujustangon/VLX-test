# eli5

```
/eli5 how does DNS work
```

Builds a sourced explainer page with four reading depths (ELI5, Beginner, Detailed, Expert), inline citations, a source trail, one visual map and related questions.

## Where it comes from

- **Page format:** modelled on [eli5.cc](https://eli5.cc), a visual answer engine by Digiwares. eli5.cc is a website and publishes no skill; this skill only follows the shape of its public pages (four depths on one source trail, numbered citations, source labels, a visual, related questions).
- **Writing rules adapted from these open-source eli5 skills:**
  - [anthropics/claude-plugins-community — eli5](https://github.com/anthropics/claude-plugins-community/tree/main/eli5): explain to someone who knows nothing, big pictures, few words.
  - [DreambigOu/ELI5](https://github.com/DreambigOu/ELI5) (MIT): what, then analogy, then detail, then why it matters; never talk down.
  - [mblode/agent-skills — eli5](https://github.com/mblode/agent-skills/tree/main/skills/eli5) (MIT): keep identifiers and numbers verbatim, no minimizers, analogies only when they explain the mechanism.
  - [getcompanion-ai/feynman — eli5](https://github.com/getcompanion-ai/feynman/tree/main/skills/eli5) (MIT): separate what the source shows from interpretation.
  - [nicknisi/skills — eli5](https://github.com/nicknisi/skills/tree/main/eli5): one idea per section, one-sentence takeaway.

The text of `SKILL.md` was written for this repository; no file was copied from the projects above.
